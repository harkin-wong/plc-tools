**新建项目**

1. 主程序: 

   - 数据名: main
   - 数据类型: **程序块**
   - 执行类型: **扫描执行型**
   - 文件名(添加目的的程序文件): **与数据名相同**, 也就是main

2. 按功能添加不同子程序:

   - 数据名: 按功能见名知义
   - 数据类型: **程序块**
   - 执行类型: **待机执行型**
   - 文件名: **与数据名相同**

3. 调用子程序

   - 在主程序中, 通过`CALL P0`方式调用子程序, `P0`为子程序指针;
   - 在子程序文件第一行的左母线左边空白处该指针, 如`P0`.
   - 子程序逻辑结束, 要使用`RET`进行子程序的结束处理

4. 子程序中嵌套调用子程序, 也是用上述框架配置及调用方式

5. 简单示例:

   ```iecst
   // main
   LD SM402
   SET M0
   LD M0
   CALL P0
   ```

   ```iecst
   // motor_run
   P0	// 第一行左母线左边空白处理, 直接键入"P0"标记该子程序指针
   LD X0
   OUT Y0
   LD Y0
   CALL P10
   RET
   ```

   ```iecst
   // motor_xxx
   P10
   LD Y0
   OUT Y1
   RET
   ```
