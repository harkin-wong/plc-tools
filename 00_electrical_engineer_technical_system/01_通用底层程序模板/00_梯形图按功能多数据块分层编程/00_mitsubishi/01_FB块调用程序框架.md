三菱FX5U/GX Works3 FB块完整框架

> 要点:
>
> - **FB 必须实例化**, 每个调用都要有独立实例;
> - `EN/ENO` 是标准使能引脚, 推荐必加;
> - FB 内部变量分 `VAR_INPUT / VAR_OUTPUT / VAR_IN_OUT / VAR`, 按需要定义局部标签或全局标签

# 一. FB块本体定义(新建FB)

---

1. 新建FB

	- 数据类型: **FB**
	- 数据名: 遵循命名规范原则, 使用"小驼峰(camelCase)/大驼峰(PascalCase)/蛇形命名(snake_case)/大写下划线(SCREAMING_SNAKE_CASE)/短横线(kebab-case)"其中一种, 通常使用**蛇形命名(snake_case)+fb前缀**, 如: **fb_cylinder_control, 气缸控制FB**
	- 程序语言: **LD(梯形图)/ST**, 个人建议使用**ST**
	- 使用EN/ENO: **是,** 推荐使用
	- 添加目标的FB文件: **<与数据名相同>**
	- FB的类型: **子程序类型**

2. 最简空 FB 模板
	```iecst
	FUNCTION_BLOCK fb_template
	VAR_INPUT
	    i_is_en : BOOL;
	END_VAR
	VAR_OUTPUT
	    o_is_eno : BOOL;
	END_VAR
	VAR
	    // internal
	END_VAR
	
	o_is_eno := i_is_en;
	IF i_is_en THEN
	    // 用户逻辑
	END_IF;
	
	END_FUNCTION_BLOCK
	```

# 二. 主程序调用FB

---

1. 梯形图主程序

	- 右侧部件选择窗口, 把 FB 拖入网络, 填写**实例名称**(如`fb_template_1`)
	- 连接相关的引脚

2. ST主程序
	```iecst
	PROGRAM main		// 主程序名字
	VAR
	    // 声明FB实例, 每个实例独立带内部状态
	    fb_template_1 : fb_template; // 实例1
	    fb_template_2 : fb_template; // 实例2
	END_VAR
	
	// ========== FB调用语法 ==========
	// 标准写法：实例名(输入:=变量, IN_OUT:=变量);
	fb_template_1(
	    i_is_en        := TRUE,
		// 其它参数
	);
	
	fb_template_2(
	    i_is_eno        := TRUE,
	    // 其它参数
	);
	
	END_PROGRAM
	```
	

> 不管是梯形图主程序调用FB还是ST主程序调用FB, 原理都一样, 都要先创建实例

# 三.重要规则

---

1. **FB 必须实例化**, 不能直接调用 FB 类型; 多个调用必须多个实例, 每个实例保留自己的定时器、状态. FC 不需要实例
2. `EN/ENO`: EN=FALSE 时, FB 内部推荐复位输出; ENO 跟随 EN(标准 IEC 习惯)
3. IN_OUT 不能直接写常量, 必须填变量 / 标签
4. 结构化工程才支持完整 FB; 简单工程必须勾选【使用标签】才能使用 FB
5. FB 内部不要直接写 X/Y/M 全局地址, 全部用接口引脚, 方便复用
