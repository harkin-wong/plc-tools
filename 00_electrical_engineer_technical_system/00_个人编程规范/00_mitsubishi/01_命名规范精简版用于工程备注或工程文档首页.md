# PLC IEC61131-3 ST 命名规范・精简版

适用: GX Works3 / FX5U，FB、FC、标签、结构体、枚举

### ✅ 核心规则

1. 标识符: **字母、数字、下划线`_`; 不能数字开头; 禁止中文、空格、短横线`-`; 避开 ST 关键字**

2. 风格统一: 变量 / 标签默认 **snake_case**; FB/FC/STRUCT/ENUM 类型名 PascalCase; 常量 SCREAMING_SNAKE_CASE

3. 前缀约定(项目强制)

	| 前缀  | 类型               | 示例                  |
	| ----- | ------------------ | --------------------- |
	| i_    | FB 输入引脚        | `i_start_btn`         |
	| o_    | FB 输出引脚        | `o_motor_run`         |
	| io_   | IN_OUT 引脚        | `io_set_speed`        |
	| r_    | 保持型 Retain 变量 | `r_total_product_cnt` |
	| g_    | 全局变量           | `g_system_mode`       |
	| cfg_  | 配置参数           | `cfg_accel_time`      |
	| stat_ | 状态机变量         | `stat_idle`           |
	| tmp_  | 临时局部变量       | `tmp_calc_rpm`        |
	| fb_   | FB 实例            | `fb_conveyor`         |
	
4. 布尔变量: 使用 `is_ / has_ / enable_` 前缀

	- ✅ `is_fault`、`has_alert`、`enable_auto`
	- ❌ `fault`、`run`(语义模糊)

### ✅ 类型命名

- FB/FC: PascalCase FB: `MotorControl`; FC: `CalcPosition`
- STRUCT: PascalCase `MotorParam`; 内部成员 snake_case
- ENUM 类型: PascalCase `MachineState`; 枚举常量大写蛇形 `STATE_IDLE`
- VAR_CONSTANT: SCREAMING_SNAKE_CASE `MAX_RPM`

### ❌ 禁止

- 混搭风格: `motorRun_speed`
- 模糊命名: `a`、`data1`
- 直接把 X/Y/M/D 作为业务变量名(推荐用标签别名包装)
- 名称过长，超过 5 个单词 → 拆结构体

### ✅ 简短示例

```iecst
VAR
  fb_motor1 : MotorControl;
  cfg_max_rpm : INT := 3000;
  is_emergency_stop : BOOL;
  stat_machine : MachineState;
END_VAR
```

> 配套: 触摸屏变量尽量和 PLC 标签同名，减少映射错误; 标签备注写清用途
